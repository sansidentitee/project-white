Règles visuelles :

- blanc dominant ; gris uniquement comme nuances de relief/texte secondaire ; noir pour la typographie ; or pour les actions et états actifs ;
- neumorphisme omniprésent avec reliefs doux, ombres doubles et éléments légèrement encastrés ;
- typographie serif éditoriale pour titres/éléments majeurs et sans-serif système pour les informations fonctionnelles ;
- très peu de couleur, aucune décoration SaaS générique ;
- sidebar fixe à 4 entrées ; avatar `A` ; bouton `+` global ;
- le mode Focus supprime presque toute l’interface pour réduire les distractions.
